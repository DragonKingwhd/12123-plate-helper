# 交管 12123 北京市车牌选号与号段监控助手 (小型新能源绿牌 & 燃油车蓝牌双模版)

专为北京市车主在交管 12123 上选号设计的本地辅助与自编策略工具。

---

## ⚡️ 北京市小型新能源汽车（绿牌）核心特征与实测规律

1. **专段专用核心字母**：
   - 第二位字母由 **`P`** 垄断（如 `京AP` 系列，偶尔穿插 `京AG`、`京AF`）；
   - 第三位字母大范围轮动循环（`京APX`、`京APY`、`京APT`、`京AGG`、`京AGS` 等）；
   - 标准号牌格式为 6 位序号编码：`京A·PXxxxx`（如 `京A·PX9100`、`京A·PY3333`、`京A·PY6666`）。
2. **高频、海量、多批次并发投放**：
   - 新能源放号密度极大，单日常见多批百连号并发（如 9月6日深夜连发 0000、8000、4500、2900 等号段）。
3. **科学选号“两阶段实战战术”**：
   - **7天内最新号段（如 9月7日刚出的 `京APX9100`、`京APY3300`）**：处于“仅限随机保护期”，自编未开放，但此时号池最满、好号最多，**建议直接用【随机选号】去碰大运**；
   - **超过7天的历史号段（如 8月31日 `京APY0800`、8月30日 `京APT0300` 及更早）**：全面解锁自编，**这是自编选号的主战场**！利用本工具排除4、挑选连号、豹子号、顺子号，直接在【自编选号】中提交！

## 🌐 使用方式

- 打开部署站点 [12123.dragonkingai.com](https://12123.dragonkingai.com/) 使用网页版选号沙盘。
- 直接打开仓库中的 [`index.html`](./index.html) 也可以离线使用沙盘（无需依赖）。
- 需要加密选号助手时，打开 [`helper.html`](./helper.html)，输入密码解锁。

## 💻 终端 Python CLI 用法

```bash
# 1. 查看北京市新能源绿牌（京AP/京AG）号段 7 天解锁状态看板
python3 plate_helper.py --type nev --check

# 2. 为已解锁自编的号段（例如 京APT 0300~0399）筛选高优自编车牌：排除4，优先8、6、9
python3 plate_helper.py --type nev --prefix 京APT --start 300 --end 399 --exclude 4 --prefer 8,6,9 --limit 15

# 3. 筛选 9月6日放出的四连顶级豹子号段（例如 京APY 6600~6699）
python3 plate_helper.py --type nev --prefix 京APY --start 6600 --end 6699 --pattern 豹子,双对
```

```

# 4. 运行【低竞争 · 高命中捡漏策略】（避开秒光雷区，成熟号段高概率一次锁定）
python3 plate_helper.py --type nev --prefix 京APT --start 300 --end 399 --strategy smart --limit 15

# 5. 运行【极品靓号冲刺模式】（适合新放号第一时间抢编）
```
